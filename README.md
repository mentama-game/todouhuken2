# 都道府県2 - 記憶だけで都道府県

[ゲームで遊ぶ](https://mentama-game.github.io/todouhuken2/)

ランダムに出題される都道府県の輪郭を、15秒以内に描くブラウザゲームです。<br />
指やマウスで何度でも描き足し、消しゴムで修正できます。

## 遊び方

1. 「スタート」でお題と15秒のカウントダウンが始まります。
2. 北を上にして、最大の陸地区域の輪郭を描きます。
3. 時間が来ると正解の形と比較し、結果を表示します。

位置と大きさを揃えた後、重なり率85%以上かつ輪郭ずれ5%以内で正解です。<br />
輪郭ずれは双方の輪郭から測った距離の95%点を、長辺に対する割合で表示します。<br />
閉じた区域が複数ある場合は最大の区域で判定します。

## 結果の保存と共有

県名・正誤・割合・描いた形と正解を載せたPNG画像を保存できます。<br />
「画像付きで共有」は対応端末の共有メニューを開きます。<br />
Xを選べない端末では画像を保存し、「Xの投稿画面を開く」から手動で添付してください。<br />
文章用のリンクだけで画像を自動添付することはできません。<br />
X公式APIやログイン連携は使用しません。

ゲームの描画・採点・画像生成はブラウザ内で行います。<br />
明示的な共有操作以外で回答をアップロードせず、プレイ履歴の永続保存は行いません。

## ファイル構成

`index.html`、`style.css`、`game.js` が画面・ゲーム操作、`geometry.js` と `judge-worker.js` が判定、`result-image.js` がPNG生成、`data/` が正解輪郭と出典です。<br />
開発環境・検証ログは配布していません。

## ローカルで開く

このディレクトリで、Pythonの静的サーバーを起動できます。

```bash
python -m http.server 8000 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:8000/` を開いてください。<br />
ES modules・Worker・JSONを使うため、HTMLファイルのダブルクリックでは動作しません。
